@deck nclex-strategy | NCLEX Strategy & Management | Management of Care
@topic Management of Care
@tag ST1
"Further teaching needed" means => Pick the INCORRECT statement.
SATA strategy => Treat each option as true or false; there is no fixed number of correct answers.
@tag ST2
ABCs => Airway, Breathing, Circulation: airway first.
Maslow priority order => Physiological, safety, love/belonging, esteem, self-actualization.
Priority rules => Acute before chronic; unstable before stable; actual before potential.
Nursing process (ADPIE) => Assessment, Diagnosis, Planning, Implementation, Evaluation.
First action when client is stable and assessment is an option => Assess before you intervene.
@tag MC1
Tasks the RN cannot delegate => Assessment, teaching, care planning, evaluation, and care of unstable clients.
UAP can do => ADLs, vitals on stable clients, I&O, ambulating, bathing, feeding stable clients.
LPN/LVN can do => Stable client care, wound care, oral/IM/SQ meds, reinforcing teaching; not initial assessment or teaching new content.
Five rights of delegation => Task, circumstance, person, direction/communication, supervision/evaluation.
@tag MC2
Who obtains informed consent? => The provider performing the procedure; the nurse witnesses the signature.
Advance directive => Document stating a client's wishes for care if they lose decision-making ability.
HIPAA => Protects the privacy and confidentiality of client health information.
Autonomy => The client's right to make their own decisions.
Beneficence vs. nonmaleficence => Do good vs. do no harm.
Incident report => Filed per policy; never mentioned in the client's chart.
@tag MC3
Triage red => Emergent: life-threatening but salvageable.
Triage yellow => Urgent: serious but can wait.
Triage green => Minor: walking wounded.
Triage black => Expectant: unlikely to survive or deceased.
@deck nclex-safety | NCLEX Safety, Infection Control & Health Promotion | Safety & Infection Control
@topic Safety & Infection Control
@tag SI1
Airborne precautions diseases => TB, measles (rubeola), varicella (chickenpox), disseminated zoster.
Airborne precautions require => Negative-pressure room and N95 respirator.
Droplet precautions diseases => Influenza, pertussis, mumps, rubella, bacterial meningitis, mycoplasma pneumonia.
Contact precautions diseases => MRSA, VRE, C. difficile, scabies, RSV, norovirus.
Hand hygiene for C. difficile => Soap and water (alcohol does not kill spores).
PPE donning order => Gown, mask/respirator, goggles/face shield, gloves.
PPE doffing order => Gloves, goggles/face shield, gown, mask, then hand hygiene.
Protective environment => For severely immunocompromised clients (neutropenia, transplant).
@tag SI2
Restraints are => A last resort; require a provider order and frequent monitoring.
RACE => Rescue, Alarm, Contain, Extinguish/Evacuate.
PASS => Pull, Aim, Squeeze, Sweep.
@tag SI3
Sterile field border considered contaminated => The outer 1 inch.
A wet sterile field is => Contaminated.
Never do with used needles => Recap them.
@topic Health Promotion & Maintenance
@tag HP1
Erikson: infant => Trust vs. mistrust.
Erikson: toddler => Autonomy vs. shame and doubt.
Erikson: preschool => Initiative vs. guilt.
Erikson: school-age => Industry vs. inferiority.
Erikson: adolescent => Identity vs. role confusion.
Piaget: preoperational => Ages 2 to 7; egocentric, magical thinking.
Piaget: concrete operational => Ages 7 to 11; logical thinking about concrete things.
Infant sleep safety => Back to sleep on a firm surface with no loose bedding.
@tag HP2
Naegele's rule => First day of LMP − 3 months + 7 days.
Preeclampsia signs => BP 140/90 or higher after 20 weeks, proteinuria, headache, visual changes, hyperreflexia.
Magnesium sulfate toxicity signs => Absent DTRs, RR under 12, urine output under 30 mL/hr.
Antidote for magnesium sulfate => Calcium gluconate.
Boggy fundus => Massage the fundus and check for a full bladder.
Lochia stages => Rubra (red), serosa (pink-brown), alba (yellow-white).
RhoGAM timing => About 28 weeks and within 72 hours after delivery of an Rh-positive baby.
Apgar score => Rated 0–10 at 1 and 5 minutes; 7–10 is reassuring.
@tag HP3
Primary prevention => Prevents disease (immunizations, healthy living).
Secondary prevention => Early detection (screenings).
Tertiary prevention => Limits complications and rehabilitates.
Best method to confirm client learning => Teach-back / return demonstration.
@deck nclex-psych-comfort | NCLEX Psychosocial & Basic Care | Psychosocial Integrity
@topic Psychosocial Integrity
@tag PS1
Therapeutic response style => Open-ended, reflective, focused on feelings.
Communication blocks => "Why" questions, false reassurance, advice, changing the subject.
@tag PS2
Denial => Refusing to accept reality.
Projection => Attributing one's own unacceptable feelings to others.
Displacement => Shifting emotions from the real target to a safer one.
Kubler-Ross stages => Denial, anger, bargaining, depression, acceptance.
Priority for a suicidal client => Safety: maintain a safe environment with close observation.
@tag PS3
Lithium therapeutic range => 0.6 to 1.2 mEq/L.
Lithium toxicity signs => Coarse tremor, vomiting, diarrhea, confusion, ataxia.
MAOI dietary restriction => Avoid tyramine (aged cheese, cured meats) to prevent hypertensive crisis.
Neuroleptic malignant syndrome => High fever, rigidity, altered mental status after antipsychotic use.
Alcohol withdrawal timeline => Begins 6–24 hours; delirium tremens 48–96 hours.
Naloxone => Opioid antagonist; monitor because it may wear off before the opioid.
@topic Basic Care & Comfort
@tag BC1
Stage 1 pressure injury => Intact skin with non-blanchable redness.
Stage 4 pressure injury => Full-thickness loss with exposed muscle, tendon, or bone.
Repositioning frequency => At least every 2 hours.
Braden scale => Tool that assesses risk for pressure injury.
@tag BC2
Positioning for tube feeding => Head of bed at least 30–45 degrees.
Healthy stoma color => Pink to red and moist.
Dusky/black stoma => Poor blood supply; notify provider immediately.
@tag BC3
Pain assessment principle => Pain is whatever the client says it is.
Signs of approaching death => Mottling, Cheyne-Stokes respirations, decreased intake.
Hospice => Comfort-focused care for clients with a prognosis of about 6 months or less.
@deck nclex-pharm | NCLEX Pharmacology & Antidotes | Pharmacological & Parenteral Therapies
@topic Pharmacological & Parenteral Therapies
@tag PH1
Two patient identifiers => Name and date of birth (never room number).
High-alert medications => Insulin, heparin, opioids, concentrated potassium, chemotherapy.
Concentrated potassium chloride IV push => Never; can cause cardiac arrest.
Do not crush => Enteric-coated and extended-release medications.
Preferred IM site for adults => Ventrogluteal.
@tag PH2
Only fluid compatible with blood => 0.9% normal saline.
Transfusion reaction first action => Stop the transfusion; keep IV open with saline using new tubing; notify provider.
Infiltration signs => Swelling, coolness, pallor, pain at the IV site.
Isotonic IV fluids => 0.9% NaCl, lactated Ringer's.
@tag PH3
ACE inhibitor side effects => Dry cough, hyperkalemia, angioedema.
Beta blocker nursing check => Heart rate and blood pressure; hold for bradycardia/hypotension.
Loop diuretic electrolyte concern => Hypokalemia.
Statin teaching => Report muscle pain; liver enzymes monitored.
Warfarin monitoring and antidote => INR (2–3); vitamin K.
Heparin monitoring and antidote => aPTT; protamine sulfate.
Digoxin: hold if => Apical HR under 60 in an adult.
Digoxin toxicity signs => Nausea, vomiting, visual changes (yellow-green halos), dysrhythmias.
Acetaminophen antidote => Acetylcysteine.
Opioid antidote => Naloxone.
Benzodiazepine antidote => Flumazenil.
Digoxin antidote => Digoxin immune fab.
@deck nclex-labs-fluids | NCLEX Labs, Fluids & Physiological Adaptation | Reduction of Risk Potential
@topic Reduction of Risk Potential
@tag RR1
Normal sodium => 135 to 145 mEq/L.
Normal potassium => 3.5 to 5.0 mEq/L.
Normal creatinine => About 0.6 to 1.2 mg/dL.
Normal platelet count => 150,000 to 400,000/mm³.
Therapeutic INR on warfarin => 2 to 3.
Best kidney function marker => Serum creatinine.
Troponin rise => Myocardial injury.
@tag RR2
Who obtains surgical consent? => The surgeon, before sedation.
Evisceration action => Cover with sterile saline-soaked dressing, low Fowler's with knees bent, call surgeon.
Postoperative hemorrhage signs => Tachycardia, falling BP, restlessness, saturated dressing.
@tag RR3
Early sign of shock => Restlessness/anxiety and tachycardia (hypotension is late).
DVT care => Do not massage; elevate leg and notify provider.
PE signs => Sudden dyspnea, chest pain, tachycardia, anxiety.
After bronchoscopy => NPO until the gag reflex returns.
@topic Physiological Adaptation
@tag PA1
Normal pH => 7.35 to 7.45.
Normal PaCO2 => 35 to 45 mm Hg.
Normal HCO3 => 22 to 26 mEq/L.
ROME => Respiratory Opposite, Metabolic Equal.
Respiratory acidosis ABG => Low pH, high PaCO2.
Metabolic acidosis causes => DKA, diarrhea, renal failure, lactic acidosis.
Metabolic alkalosis causes => Vomiting, NG suction.
@tag PA2
MI initial care => ECG, aspirin (chewed), oxygen if hypoxic, nitroglycerin, pain control, rapid reperfusion.
Left-sided HF signs => Crackles, dyspnea, orthopnea, cough.
Right-sided HF signs => Peripheral edema, JVD, weight gain.
Report weight gain of => 2–3 lb in a day or 5 lb in a week (heart failure).
COPD oxygen => Low flow (1–2 L/min), target SpO2 about 88–92%.
@tag PA3
Hypoglycemia treatment (conscious) => 15 g fast-acting carbohydrate, recheck in 15 minutes.
DKA hallmarks => High glucose, ketones, acidosis, Kussmaul respirations.
FAST => Face drooping, Arm weakness, Speech difficulty, Time to call 911.
Cushing's triad => Hypertension with widened pulse pressure, bradycardia, irregular respirations.
Seizure care => Protect head, turn to side, time it, never put anything in the mouth.
Increased ICP positioning => Head of bed about 30 degrees, head midline.
