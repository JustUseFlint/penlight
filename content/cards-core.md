@deck core-ap | Anatomy & Physiology Core | Anatomy & Physiology
@topic Anatomy & Physiology
@tag AP1
Negative feedback => A response that reverses a change to restore homeostasis (e.g., sweating).
Four tissue types => Epithelial, connective, muscle, nervous.
@tag AP2
Osteoclast vs. osteoblast => Osteoclasts break down bone; osteoblasts build bone.
Skeletal muscle contraction trigger => Nerve signal causing calcium release; actin and myosin slide using ATP.
@tag AP3
Frontal lobe => Movement, judgment, speech production.
Occipital lobe => Vision.
Cerebellum => Balance and coordination.
Sympathetic vs. parasympathetic => Fight or flight vs. rest and digest.
@tag AP4
ADH deficiency => Diabetes insipidus: large volumes of dilute urine and thirst.
Aldosterone => Retains sodium and water, excretes potassium.
Cortisol => Stress hormone, raises glucose, anti-inflammatory.
@tag AP5
Cardiac output => Heart rate × stroke volume.
Preload vs. afterload => Preload: ventricular stretch before contraction. Afterload: resistance the ventricle pumps against.
S1 vs. S2 => S1: AV valves close. S2: semilunar valves close.
@tag AP6
Surfactant => Lowers alveolar surface tension and prevents collapse.
Main stimulus to breathe => Rising CO2 (falling pH).
@tag AP7
Kidney hormones made => Erythropoietin (red blood cells) and renin (blood pressure).
Normal urine output => At least 30 mL/hr (0.5 mL/kg/hr).
@tag AP8
IgG => Most abundant antibody; crosses the placenta.
IgE => Allergy and anaphylaxis antibody.
@deck core-pharm | Pharmacology Core | Pharmacology
@topic Pharmacology
@tag PM1
Steady state => Reached after about 4 to 5 half-lives.
Narrow therapeutic index drugs => Digoxin, lithium, warfarin, phenytoin.
First-pass effect => Liver metabolism of an oral drug before it reaches the circulation.
@tag PM2
Beta blocker suffix => -olol.
ACE inhibitor suffix => -pril.
ARB suffix => -sartan.
Statin suffix => -statin.
Spironolactone risk => Hyperkalemia (potassium-sparing diuretic).
Nitroglycerin SL rule => If pain persists 5 minutes after the first dose, call 911.
@tag PM3
Heparin antidote => Protamine sulfate.
Warfarin antidote => Vitamin K.
Enoxaparin syringe tip => Do not expel the air bubble before injecting.
@tag PM4
Mixing insulin => Clear (regular) before cloudy (NPH).
Insulin given IV => Regular (short-acting) insulin only.
Prednisone teaching => Never stop abruptly; taper to prevent adrenal insufficiency.
@tag PM5
Aminoglycoside toxicity => Nephrotoxicity and ototoxicity.
Vancomycin rapid infusion => "Red man syndrome" (flushing).
Metronidazole teaching => Avoid alcohol.
@tag PM6
Opioid reversal => Naloxone.
NSAID risks => GI bleeding, kidney injury, bleeding tendency.
Acetaminophen overdose organ => Liver.
@tag PM7
Benzodiazepine reversal => Flumazenil.
SSRI onset => 2 to 6 weeks.
Phenytoin side effect => Gingival hyperplasia.
@tag PM8
Rescue inhaler order => Use the quick-relief (albuterol) before the controller steroid inhaler.
After inhaled steroid => Rinse mouth to prevent thrush.
@deck core-medsurg | Med-Surg Basics Core | Med-Surg Basics
@topic Med-Surg Basics
@tag MS1
Left-sided heart failure => Pulmonary congestion: crackles, dyspnea, orthopnea.
Right-sided heart failure => Systemic congestion: edema, JVD, weight gain.
@tag MS2
Pursed-lip breathing => Prolongs exhalation and keeps airways open in COPD.
Chest drainage system position => Upright and below chest level.
@tag MS3
Hypothyroid vs. hyperthyroid => Hypo: slow and cold. Hyper: fast and hot.
Rule of 15 => 15 g carbohydrate, recheck in 15 minutes.
@tag MS4
Hepatic encephalopathy treatment => Lactulose to lower ammonia.
Appendicitis precaution => No heat and no laxatives.
@tag MS5
Dialysis fistula arm => No BP, venipuncture, or IVs; check thrill and bruit.
Peritonitis sign in PD => Cloudy outflow with abdominal pain.
@tag MS6
Ischemic vs. hemorrhagic stroke => Clot vs. bleed.
Guillain-Barré risk => Respiratory failure from ascending paralysis.
@tag MS7
Six Ps of neurovascular assessment => Pain, pallor, pulselessness, paresthesia, paralysis, poikilothermia.
Compartment syndrome hallmark => Pain out of proportion that is unrelieved by medication.
@tag MS8
First-line treatment for anaphylaxis => IM epinephrine.
Neurogenic shock signature => Hypotension with bradycardia and warm, dry skin.
@deck core-fund | Fundamentals Core | Fundamentals
@topic Fundamentals
@tag FU1
Subjective vs. objective data => Subjective: what the client says. Objective: measurable or observed.
SBAR => Situation, Background, Assessment, Recommendation.
Correcting a charting error => Single line through it, write correction, initial and date.
@tag FU2
Abdominal assessment order => Inspection, auscultation, percussion, palpation.
Normal adult respiratory rate => 12 to 20 breaths per minute.
Normal adult pulse => 60 to 100 beats per minute.
@tag FU3
Chain of infection links => Agent, reservoir, portal of exit, transmission, portal of entry, susceptible host.
Hand hygiene for visibly soiled hands => Soap and water.
@tag FU4
Crutch weight-bearing => On the hands, not the axillae.
Fowler's position => Head of bed elevated 45 to 60 degrees.
@tag FU5
Best interpreter choice => Qualified medical interpreter (not family).
Teach-back => The client explains or demonstrates in their own words.
@tag FU6
Calories per gram => Carbohydrate 4, protein 4, fat 9.
BMI formula => Weight (kg) ÷ height (m)².
@tag FU7
Wound healing phases => Hemostasis, inflammation, proliferation, maturation.
Secondary intention healing => Wound heals from the base up with granulation.
@tag FU8
DNR order requirement => A written provider order.
Four elements of negligence => Duty, breach, causation, harm.
